# Léa Spagnuolo — Portfolio musique & festivals

Site indépendant consacré à la musique live, aux festivals, à la communication et à la production événementielle.

## Déploiement sur un second dépôt GitHub
1. Créer un nouveau dépôt public, par exemple `portfolio-musique`.
2. Décompresser cette archive.
3. Ajouter à la racine du dépôt : `index.html`, `styles.css`, `app.js`, `CV_Lea_Spagnuolo.pdf` et le dossier `Media/`.
4. Copier dans `Media/` les médias du portfolio que tu souhaites réutiliser. Le code conserve les chemins et noms de fichiers existants (attention aux majuscules/minuscules).
5. Dans GitHub : **Settings → Pages → Deploy from a branch → main → /(root)**.
6. L'adresse du site sera `https://TON-PSEUDO.github.io/portfolio-musique/` si le dépôt s'appelle `portfolio-musique`.

## Interactions
- Vinyle cliquable dans la section Expériences : Face A (expériences professionnelles) / Face B (bénévolat en festivals).
- Filtres de projets et médias interactifs conservés.
- Les stickers de festivals sont des lettrages éditoriaux provisoires, pas des reproductions officielles de logos. Les vrais fichiers de logos peuvent être ajoutés ensuite en SVG/PNG dans `Media/`.

## Disponibilités affichées
- Stage de 9 semaines à partir du 22 mars 2027.
- Disponible à partir de juin 2027 pour un stage avec ou sans convention.

## Important
Ce dépôt est indépendant du portfolio Motorsport. Les deux sites peuvent être publiés séparément. Ne pas écraser le dépôt Motorsport avec ces fichiers.
